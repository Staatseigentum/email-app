MailWave

Ein moderner Desktop-E-Mail-Client. Läuft vollständig lokal auf deinem Rechner.

Was ist das?

MailWave ist eine Open-Source-Desktop-App (Electron), die sich direkt mit deinen vorhandenen E-Mail-Postfächern verbindet – per IMAP/SMTP oder über die Anmeldung bei Google bzw. Microsoft. Es gibt keinen MailWave-Server: alle Daten bleiben auf deinem Gerät.

Funktionen

  • Mehrere Konten parallel
  • E-Mails lesen, schreiben, beantworten, weiterleiten
  • Desktop-Benachrichtigungen bei neuer Post
  • Browser-Login (OAuth) für Google und Microsoft
  • Zugangsdaten lokal über den System-Schlüsselbund verschlüsselt
